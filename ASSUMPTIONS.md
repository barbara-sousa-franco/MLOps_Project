## Data
- **Raw:** `data/01_raw/portugal_listings.csv` — 135,536 rows, 25 columns.
- **Target:** `Price` in **EUR** (regression). Has ~0.2% nulls -> rows without a target are
  **dropped in ingestion** (target must exist). TODO: confirm currency/scale in EDA.
- **`PublishDate`:** **~78% null** (only ~21% have a date, almost all from Oct 2024). Therefore:
  - A temporal split for `ref_data`/`ana_data` is **NOT** used — a reproducible **random split**
    is used instead (`seed`, `ingestion.reference_fraction=0.8`).
  - As `event_time` in the feature store it is reserved for Phase 5 (with the null caveat).
- **`ref_data` / `ana_data`:** generated by `ingestion.split_reference_analysis` (ref = training
  baseline; ana = "new batch" for drift + inference). TODO (Phase 3): inject artificial drift
  into `ana_data` to demonstrate detection.
- **Known outliers:** at least one price of ~1.38 billion EUR and negative/impossible areas
  (see EDA) — handled in `preprocessing_train.clean_data`. TODO: document applied limits.
- **Missing values:** very high null rates in several columns (ConservationStatus 86%, BuiltArea 80%,
  GrossArea 80%, Floor 79%, LotSize 71%, NumberOfBedrooms 65%...). Imputation strategy —
  or dropping overly empty columns — defined in `parameters_preprocessing.yml`. TODO: justify.

## Model
- Candidates: RandomForest / GradientBoosting (+ XGBoost/LightGBM optional).
- Selection metric: **RMSE** (lower = better). Baseline = mean of `Price`.
- Champion/challenger managed via **MLflow Model Registry**.

## Limitations / risks (see also the "risks & mitigations" section of the report)
- **Pandas-only:** does not scale to much larger data -> Spark/Polars as mitigation.
- **External Hopsworks:** depends on API key + cloud service; `to_feature_store=false` allows
  running from local CSVs.
- **Optuna `n_trials` limited by time:** quality vs duration trade-off.
- **Artificial drift** used to demonstrate detection; in production it would be continuous.
